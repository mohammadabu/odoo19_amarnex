Document Management System | Document Management | Documents | Attachment Documents
========================
- This module offers a simple yet powerful way to manage documents, including features like directories (folders), 
   labels(tags), exports, numbering, version control, and access control via security groups.

Features
============
- User Group and Manager Group Security
- Directory / Folder View Based on Document modules
- Document versions
- Document numbering
- Filter by tags / labels
- Document Share
- Document Send by Email
- Export Multiple Documents to Zip

Installation
============
- Copy ais_document_management module to addons folder
- Install the module normally like other modules.
